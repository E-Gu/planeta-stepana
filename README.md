# Планета Степана

Спокойный градостроитель на пыльной планете, версия для Степана. Таймеров нет, проиграть нельзя.

**Играть: https://e-gu.github.io/planeta-stepana/**

Здесь лежит только собранная игра. Её исходники хранятся в другом месте.

## Как поставить на Android (телефон и планшет)

1. Откройте ссылку выше в **Chrome**.
2. Chrome сам предложит **«Установить приложение»** внизу экрана. Если не предложил: меню ⋮ справа вверху → **«Установить приложение»** (или «Добавить на главный экран» → «Установить»).
3. На главном экране появится значок «Планета Степана»: купол и белый пухляк в радужном ошейнике.
4. Дальше открывайте игру **этим значком**. Она откроется на весь экран и без сети.

## Где сохранения

Игра сохраняется сама, в памяти этого устройства. Аккаунт не нужен. В меню ⚙ → «Сохранения» есть три ячейки и прежние копии, которые игра откладывает сама.

## Как перенести колонию на другое устройство

1. Там, где колония есть: меню ⚙ → «Сохранения» → **«Скачать сохранение»**. Получится файл `planeta-stepana-….json` в «Загрузках».
2. Передайте файл на другое устройство: Quick Share, почта или Google Диск.
3. Там: меню ⚙ → «Сохранения» → **«Открыть из файла»** и выберите файл. Игра покажет, что в нём лежит, и спросит, прежде чем что-то заменить.

Скоро это будет происходить само: телефон и планшет будут подхватывать колонию друг у друга.

## Новые версии

Когда выходит новая версия, игра сама возьмёт её при следующем запуске, если есть сеть. Сохранения при этом остаются.
